# Predictive Analytics Using Historical Data

## Overview

This project focuses on forecasting future sales trends using historical sales data and machine learning techniques. The dataset is preprocessed, analyzed, and used to train a Linear Regression model that predicts future sales values.

## Objectives

- Clean and preprocess historical sales data
- Perform exploratory data analysis (EDA)
- Build a predictive model using Linear Regression
- Evaluate model performance using MAE, MSE, RMSE, and R² Score
- Visualize actual vs predicted sales trends
- Forecast future sales for the next 30 days

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
- Google Colab

## Features

- Data Cleaning and Preprocessing
- Feature Engineering from Date Attributes
- Sales Trend Analysis
- Predictive Modeling
- Forecast Visualization
- Future Sales Forecasting

## Model Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Project Outcome

The project demonstrates how historical data can be leveraged to identify patterns and forecast future sales trends, helping support data-driven business decisions.
